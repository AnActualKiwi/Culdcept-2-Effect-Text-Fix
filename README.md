# Culdcept 2 Effect Text Fix

Patches a completely unmodified **Culdcept (USA)** PS2 ISO.
The source ISO is never changed. If the output file already exists, delete or
rename it before trying again.

## Windows

1. Open [Releases](https://github.com/AnActualKiwi/Culdcept-2-Effect-Text-Fix/releases/latest)
   and download the latest release ZIP.
2. Extract the ZIP.
3. Drag your **Culdcept (USA).iso** onto **`Apply Patch.cmd`**.
4. Wait for it to finish. The patched game appears beside the source as
   `Culdcept (USA) patched.iso`.
